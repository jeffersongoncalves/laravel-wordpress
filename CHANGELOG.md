# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-08

First release.

WordPress REST API client for Laravel, built on Laravel's HTTP client with HTTP Basic (Application Password) auth:

- Posts and pages: list, get, create, update, delete (trash or force)
- Media: list, get, upload (raw body + Content-Disposition), update, delete
- Categories and tags: full CRUD
- Comments: full CRUD
- Users: list, get, current user (/users/me)
- Publishable config (base URL, credentials, REST namespace) and `Wordpress` facade
- Laravel Boost guidelines and development skill
